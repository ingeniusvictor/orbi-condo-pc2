# OC-PC2-26 — evidencias por sistema
Las fichas de mantenimiento muestran un botón «Ver evidencias» y un historial de publicaciones aprobadas. El catálogo de demostración está vacío deliberadamente: no se inventan trabajos, fechas, fotografías ni informes.
La función de consulta filtra por sistema y por estado accepted con fecha de publicación. En producción, el servidor debe aplicar autorización y filtrado, nunca confiar en una lista del navegador.
Para la etapa de integración: enlazar orden de trabajo, sistema, proveedor, fecha, anexos privados, aceptación administrativa y publicación; URL firmada o endpoint autorizado para cada descarga. No confundir ausencia de publicación con falta de mantenimiento.
