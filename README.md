# ORBI Condo · Parque Ciudadano II

Showcase visual de mantenimiento y comunidad para Parque Ciudadano II, Rancagua.

## Objetivo
Transformar el calendario técnico de mantenciones en una experiencia clara, atractiva y replicable. PC2 es el primer caso demostrativo; la arquitectura de contenido mantiene sistemas, proveedores y certificaciones separados de la interfaz.

## Fuente inicial
Calendario de mantención PC2 proporcionado por la comunidad. Los proveedores con presencia web se marcan como verificados solo cuando su identidad puede confirmarse razonablemente. Nombres ambiguos permanecen pendientes.

## Desarrollo
- Next.js 16 / React 19
- Framer Motion
- Responsive mobile-first
- Datos editables en `data/community.ts`

```bash
npm install
npm run dev
npm run build
```
